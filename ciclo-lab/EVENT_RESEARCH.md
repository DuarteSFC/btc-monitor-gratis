# EV01 — event-first research, 27 November 2026
Fixed before results. Development scope Feb 2021–Dec 2023 and Feb–Sep 2026; January warmup each scope. Existing verified perpetual minute, mark, funding archives only. 2024–25 locked.
- Every 15-minute closed decision with entry at next minute open after 1 minute delay; 5-minute expansion deferred until initial audit. Hourly decisions are nested subset. Require 48h full contiguous forward path and causal complete features; distinguish missing from negative. Exclude last 3 UTC days in each scope. Full-path availability is an outcome eligibility constraint, not a live input.
- Targets 1/2/3/5%, stop half target, horizons 2/4/12/24/48h; conservative stop first for same-minute ties, outcomes up-first/down-first/timeout, median time to successful target. Report all, not pick best. These are overlapping potential decisions, not independent executed trades.
- Fixed pre-entry strata: 4h return negative/nonnegative, RSI14 on 15m below 40/40–60/above 60, 1h return positive/nonpositive, ATR14 1h relative to close >=1%/<1%, volume last 15m vs preceding 96 bars >=1.5/<1.5, 4h EMA20 above EMA60 vs not. Compare marginal event rates against common eligible baseline; no causal claims or threshold tuning. Report counts and per-year for primary 2%/1% 12h event, fixed 12h-spaced sample as overlap sensitivity. Distinct event recall is not identifiable from overlapping labels; report decision-level recall.

One open position, no leverage, risk 0.25% equity with notional cap; actual fees/slippage 14/24 bps, funding using last completed mark with counted perp fallback; conservative stop gaps and tie order, timeout at final minute close. Delay 1m only in this first diagnostic; if not profitable in both scopes under stress reject EV01 as trading policy. All years and all cases, no selecting best strata; no independent significance or deployment. Record counts, gross event diagnostics and net economic results separately.
